# Data Model: UI & Checkout Enhancements

**Date**: 2026-09-18
**Feature**: 009-ui-checkout-enhancements

## Entities

### CartItem (existing, unchanged)

Represents an item in the customer's cart. Already defined in `src/types/index.ts`.

| Field | Type | Description |
|-------|------|-------------|
| menu_item_id | string | References MenuItem.id |
| name | string | Display name |
| price | number | Price in PKR |
| quantity | number | Quantity selected |
| image_url | string \| null | Path to image |

**Storage**: localStorage via `useCart` hook (key: `"ghousia-cart"`)

### CheckoutDetails (new, ephemeral)

Customer information collected during checkout. Not persisted — exists only in React state during the checkout session.

| Field | Type | Validation |
|-------|------|------------|
| customer_name | string | Required, min 2 characters |
| phone | string | Required, valid Pakistani phone format |
| order_mode | "delivery" \| "pickup" \| "dine-in" | Required, default: "delivery" |
| address | string | Required if order_mode is "delivery" |
| branch | string | Required if order_mode is "pickup" or "dine-in" |
| notes | string | Optional, max 200 characters |

### MenuItem (existing, unchanged)

Already defined in `src/lib/menu-data.ts`. Referenced by CartItem.

### WhatsAppOrderMessage (generated, not stored)

Formatted string generated by `generateFullOrderMessage()` for WhatsApp delivery.

| Section | Content |
|---------|---------|
| Header | "NEW ORDER - Ghousia Golden Spoon" |
| Customer | Name and phone |
| Mode | Delivery/Pickup/Dine-in with address or branch |
| Items | Numbered list with name, quantity, price |
| Total | Sum of all items |
| Notes | Optional customer notes |

## Relationships

```
CartItem (many) ──> (1) MenuItem
CheckoutDetails (1) ──> (many) CartItem (generates WhatsAppOrderMessage)
```

## State Transitions

### Checkout Flow

```
[Step 1: Details] ──click "Continue"──> [Step 2: Confirm] ──click "Place Order"──> [WhatsApp Opened]
       ^                                        |
       └──────────click "Back"─────────────────┘
```

### Modal Flow

```
[Menu Page] ──click item──> [Modal Open] ──click "Add to Cart"──> [Modal Open, cart updated]
                                       ──click "Continue Order"──> [Modal Close, navigate to /order]
                                       ──click X / backdrop / ESC──> [Modal Close]
```

## Validation Rules

- `customer_name` must be non-empty and at least 2 characters
- `phone` must match Pakistani phone format (03XX-XXXXXXX or +92XXXXXXXXXX)
- `order_mode` must be one of: "delivery", "pickup", "dine-in"
- `address` is required when `order_mode` is "delivery"
- `branch` is required when `order_mode` is "pickup" or "dine-in"
- Cart must have at least 1 item to proceed to checkout
