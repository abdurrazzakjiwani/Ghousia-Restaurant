# Checkout Data Contract

**Date**: 2026-09-18
**Feature**: 009-ui-checkout-enhancements

## Overview

No new API endpoints are introduced. The checkout flow uses:
- Client-side state (React `useState`) for step management and customer details
- Existing `useCart` hook for cart persistence (localStorage)
- Existing `generateFullOrderMessage()` utility for WhatsApp message formatting
- WhatsApp `wa.me` deep linking for order delivery

## Data Flow

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  useCart     │────>│ CheckoutStep1│────>│ CheckoutStep2│
│  (localStorage)│   │ (details)    │     │ (confirm)    │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                                          ┌───────▼───────┐
                                          │  WhatsApp     │
                                          │  wa.me link   │
                                          └───────────────┘
```

## CheckoutDetails Schema

Used by CheckoutStep1 and CheckoutStep2:

```typescript
interface CheckoutDetails {
  customer_name: string;
  phone: string;
  order_mode: "delivery" | "pickup" | "dine-in";
  address?: string;    // Required if delivery
  branch?: string;     // Required if pickup/dine-in
  notes?: string;
}
```

## WhatsApp Message Format

Generated by existing `generateFullOrderMessage()`:

```
NEW ORDER - Ghousia Golden Spoon

Customer: {customer_name}
Phone: {phone}

Mode: {delivery|pickup|dine-in}
Address: {address}           // if delivery
Branch: {branch}             // if pickup/dine-in

Items:
1. {item_name} x{quantity} = Rs. {subtotal}
2. {item_name} x{quantity} = Rs. {subtotal}

Total: Rs. {total_amount}
Notes: {notes}               // if provided
```
